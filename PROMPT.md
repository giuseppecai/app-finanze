# Prompt da incollare in Claude Code

Copia il testo qui sotto come primo messaggio, dopo aver aperto Claude Code nella cartella del progetto (quella che contiene `CLAUDE.md`).

---

Ciao! In questa cartella c'è tutta la documentazione di un'app che voglio costruire: una PWA personale di budgeting a buste per iPhone, che lavora insieme al mio conto Revolut.

Leggi prima `CLAUDE.md`, poi tutti i file in `docs/` nell'ordine indicato, e guarda i mockup in `design/mockups/` (le istruzioni su come aprirli sono in `design/README.md`).

Poi, prima di scrivere codice:
1. Riassumimi in 10 righe cosa hai capito dell'app e delle regole più importanti (periodi dal 27 al 26, residui delle buste, Confronta con Revolut, chiusura e inizio mese, abbonamenti, prestiti FIFO).
2. Dimmi se trovi ambiguità o contraddizioni tra regole, schermate e mockup, e fammi le domande che ti servono.
3. Proponi la struttura del progetto e l'elenco dei file della milestone M0.

Lavoriamo una milestone alla volta come da `docs/06-piano-lavoro.md`: alla fine di ognuna voglio test verdi, build pulita e una lista di cose da provare sul mio iPhone. Non passare alla successiva finché non te lo dico io.

Il repository GitHub si chiamerà `app-finanze` e voglio pubblicarlo su GitHub Pages.
